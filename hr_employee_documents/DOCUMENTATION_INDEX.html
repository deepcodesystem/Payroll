✨ Key Features

Document Management

  • Upload documents with metadata
  • Organize by document types
  • Version history tracking
  • File download capability
  • Document expiry tracking

Approval Workflow

  • Multi-status workflow
  • Manager approval
  • Rejection with reasons
  • Draft reset option
  • Approval audit trail

Access Control

  • Role-based permissions
  • Record-level security
  • Manager hierarchy support
  • Visibility controls
  • Employee data protection

📁 Project Structure

The module follows Odoo's standard directory structure for easy maintenance and future upgrades. 

hr_employee_documents/
├── models/                    # Python data models
│   ├── document_type.py
│   ├── employee_document.py
│   ├── hr_employee.py
│   ├── reject_wizard.py
│   └── report.py
│
├── views/                     # XML user interface views
│   ├── document_type_views.xml
│   ├── employee_document_views.xml
│   ├── hr_employee_views.xml
│   ├── menus.xml
│   └── reject_wizard_views.xml
│
├── reports/                   # PDF reports
│   ├── report.xml
│   └── employee_document_report.xml
│
├── data/                      # Pre-configured data
